# Archived beta

This directory preserves the original Vulcan proof of concept. It is not
maintained and is not part of the release client or server.

- `client-csharp-beta/` contains the early command-group and ribbon prototype.
- `client-python-beta/` contains the PyQt5 client that executed model-generated
  Python with `exec()`.
- `server-python-beta/` contains the FastAPI and AsyncOpenAI server for that
  workflow.

Do not deploy or run the beta track in production. The maintained code lives in
`client/` and `server/` at the repository root.
